# A2L Course

A2L refrigerant guide and practice exam for HVAC techs, by Shameen.

- `index.html`: A2L Refrigerants Explained for Techs
- `quiz/`: A2L Practice Exam (questions in `quiz/questions.js`)

To view it, open `index.html` in a browser. There's nothing to install.

## Put it online (free)

1. Push this folder to a GitHub repository.
2. On GitHub, go to Settings > Pages and choose the `main` branch, root folder.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/`.
4. Optional: buy a domain (about $12 a year) and add it under Settings > Pages > Custom domain.

Study aid only. Always follow the equipment maker's instructions and your local code.
